YouTube Keyboard Blocker 1.2.0
==============================

Installation (unpacked):
1. Extract this folder.
2. Open chrome://extensions or opera://extensions.
3. Enable Developer mode.
4. Click Load unpacked.
5. Select the folder containing manifest.json.
6. Reload any YouTube tabs that were already open.

Features:
- Block selected YouTube keyboard shortcuts.
- Optional block-all mode with per-key exceptions.
- Per-key and per-shortcut customization.
- Numpad keys included by default.
- Text fields remain usable by default.
- Settings are stored with chrome.storage.sync.
- No analytics, ads, remote code, or network requests.

Languages:
English (default), French, Spanish, German, Italian, Portuguese (Brazil).
