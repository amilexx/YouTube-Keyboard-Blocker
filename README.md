# YouTube Keyboard Blocker

A simple Chromium extension that lets you disable YouTube keyboard shortcuts individually.

## Features

- Block YouTube keyboard shortcuts
- Customize blocked keys one by one
- Block numpad keys
- Optional "block all keys" mode with allowed-key exceptions
- Keeps typing available in search boxes and comments
- Supports English, French, Spanish, German, Italian and Portuguese
- Works on Chrome, Opera and other Chromium-based browsers
- No tracking, no ads, no external requests

## Installation

1. Download the latest release and extract the ZIP.
2. Open your browser's extensions page:
   - Chrome: `chrome://extensions`
   - Opera: `opera://extensions`
3. Enable **Developer mode**.
4. Click **Load unpacked**.
5. Select the extracted extension folder.
6. Reload YouTube.

## Usage

Click the extension icon to quickly enable or disable the blocker.

Open the extension options to choose exactly which keys and shortcuts YouTube is allowed to receive.

## Privacy

The extension does not collect or send any data.

Settings are stored locally using the browser extension storage API.
